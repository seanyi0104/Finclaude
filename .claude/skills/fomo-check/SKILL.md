# 从众检查
逐条问我，能算的用 Python 算：
1. 我为什么现在想买？信息来自谁？
2. 我能用三句话讲清它的赚钱逻辑吗？
3. 它历史最大回撤是多少？按我打算投入的金额，那相当于亏多少澳元？
4. 买入后它在组合里占多少？会超过 IPS 的仓位上限吗？
5. 费率多少？有没有更便宜的同类？
6. 和我已持有的产品重叠多少？（调用 /overlap）
7. 交给 devils-advocate 子代理复核。
最后把问答写入 journal/（用 journal/_template.md），建议我留出冷静期（时长在 IPS 里设定）再决定。
