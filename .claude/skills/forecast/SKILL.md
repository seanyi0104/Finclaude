# Forecast cards
Stock analysis carries no account figures and no IPS reminders (see CLAUDE.md): this skill only forecasts; positions and rules are left to /checkup.

Role: forecaster. Probabilities come only from data and models (historical statistics, option pricing and Jev via finclaude.forecast), never from numbers Claude estimates or from self-rated confidence. No buy, sell or position instructions; third-party ratings are quoted as published (original English wording) with source and date. All maths in Python. If something cannot be fetched, write 「无可靠数据」 (no reliable data) and the reason; never fill the gap.

0. Scoring (free): run finclaude.forecast.score() first, then take each source's record with scoreboard().
1. Tickers: by default every holding read by finclaude.account (US, Hong Kong and ASX); if OpenD is not running, use profile/holdings.csv and state the snapshot date. Convert codes with data.ticker_from_code (AU.IVV → IVV.AX, not the US-listed IVV). The first paragraph of the report says which markets are covered; any market that could not be read must be named, never silently skipped.
2. Data and preflight (free): forecast.risk_free() for ^IRX, then forecast.prepare(ticker, rate) for each ticker. US daily prices via Treg · Tiingo (USD 0, 20 calls a day); Hong Kong and ASX daily prices, options and analyst data via yfinance. yfinance has no options for Hong Kong or ASX listings, and ETFs usually have no analyst coverage; run during US trading hours, the US options column also shows 「无可靠数据」 (prices out of sync). Report all of this as it is. Then run finclaude.jev.preflight().
3. Jev (paid): build the rows without Jev with forecast.card_rows, then one request with forecast.jev_request(preps, rows) (each ticker × 4 horizons, one boolean question each). Use finclaude.jev.auto_budget() for max_cost_usd (automatic within USD 1 a month, no need to ask me); only when it raises CostNotApproved, list 端点 | 次数 | 单价 | 合计 (endpoint | calls | unit price | total) with finclaude.jev.quote(1) and wait for my confirmation; then call forecast.jev_odds(state, questions, max_cost_usd=that amount, save_as=<report folder>/jev_result.json). If Jev returns no probability, stop at this step and leave Jev off the cards.
4. Cards: recompute forecast.card_rows with the Jev probabilities and render each card with forecast.card_markdown; forecast.primer_markdown (built on the 1-month row of a holding that has options data, explaining the three sources and what an option is) goes into this week's Lesson page, not Decision; forecast.log_forecasts(rows) records everything in journal/forecasts.csv.
Output: key points of the cards go into this week's Decision page; the full report goes to reports/<week>/_附件/forecast/: report.html (built with finclaude.render.save_report; first paragraph: how many tickers and how many sources agree; then the primer and one card per ticker; then the scoreboard, data sources and as-of dates, costs and limitations), cards.csv (all card_rows columns) and jev_result.json.
Limitations that must be stated: historical statistics favour the companies that survived; option probabilities are risk-neutral; analyst targets are 12-month figures; it takes dozens of scored forecasts before clear differences show, and hundreds of independent forecasts to separate sources that differ only slightly; cards issued on the same day bet on the same stretch of the market and are not independent samples.
Closing line: 「教育用途，非投资建议；决定权在你。」 (education only, not investment advice; the decision is yours).
