# Weekly: wrap up last week, open the new one

A week is Monday to Friday, US Eastern time. First get the Monday of the week to close and of the week to open with weekly.close_and_open(weekly.us_day()) (on a weekday: close last week, open this week; at the weekend: close the week that just ended, open next week). I only read the weekly doc (Claude Docs, link in CLAUDE.local.md; read and write it with the docs tools, reading the doc first to get each tab's id) and the trimmed archives in reports/<week>/; everything else is yours to manage. Without a weekly doc (no Claude Docs, or no link set): write the three pages directly as reports/<week>/News.md, Decision.md and Lesson.md; every "tab" and "sub-tab" below then means those three files, and glossary marks are edited directly in profile/glossary.json. All numbers in Python; if something cannot be fetched, write 「无可靠数据」 (no reliable data) and the reason.

## A. Wrap up last week (only after the US Friday close; skip if reports/<last week>/ already has its three archives)
1. Score expired forecasts: forecast.score(), then forecast.scoreboard(). In last week's Decision, under 「到期的预测」 (forecasts due), write which forecasts expired, how many were right and each source's Brier score (a coin flip scores 0.25). If none expired, state the date of the earliest batch.
2. Holdings review and outlook: write weekly.friday_review(monday, friday) into last week's Decision (Moomoo read-only: holdings, cash, cash flows; if OpenD is not running it falls back to the snapshot in profile/ and says so). It starts with 「这周账户赚 / 亏多少澳元」 (how many AUD the account made or lost this week: total assets against last week's record in data/weekly/, excluding deposits and withdrawals), then one line per holding; this week's total is saved to data/weekly/<friday>.json for next week's comparison. While US stocks trade (pre-market, regular, after-hours, overnight), Moomoo values holdings at the price of the moment, so run this step between 20:00 Friday (end of after-hours) and 20:00 Sunday (start of overnight trading), US Eastern (convert to my local time zone from CLAUDE.local.md with Python); a reading taken during a session is noted in the review automatically. Cover US, Hong Kong and ASX holdings; name any code that could not be read, never skip it silently. Only in the first week of a month, add the 「月度体检」 (monthly check-up, /checkup); IPS reminders appear only there.
3. Trimmed archive: read last week's three sub-tabs and write reports/<last week>/News.md, Decision.md and Lesson.md (folder name from weekly.folder_name(monday)). Keep only the core conclusions and insights, not a full export; use lists, not wide tables:
   - News: the most important official events (each keeps its source link), next week's calendar, ongoing themes, sources that could not be read.
   - Decision: each stock's single-screen card, the holdings review and outlook, the forecast scores.
   - Lesson: this week's cards, and changes in my glossary marks.
   Attachments (jev_result.json, full reports) go to reports/<last week>/_附件/.
4. Memory: save what is useful across weeks (changes in my preferences, which source is more accurate, concepts I keep asking about).
5. Tell me: last week is archived and the old session can be deleted.

## B. Open the new week
1. Create the folder reports/<this week>/ (weekly.folder_name(monday)).
2. Add tabs to the weekly doc (when using one; a single batch): a parent tab named weekly.tab_name(monday) with order = weekly.tab_order(monday) (the newest week first; the 「术语表」 (glossary) tab keeps order z0 and stays last); under it, three sub-tabs, News (order a1), Decision (a2) and Lesson (a3), with subtabOf pointing to the parent. The parent tab gives the week's overview: the US Eastern dates and the matching local times (time zone in CLAUDE.local.md; convert with Python, as daylight saving may not change on the same dates), what each sub-tab holds, and a note to check the glossary first for unfamiliar words.
3. News: this week's official calendar (earnings dates of holdings and watched stocks, BLS / BEA releases, FOMC), from official pages only, each with its link; then catch up on official announcements to the latest trading day, follow ongoing themes, and add one line each for VIX and VXN: with data.get_cboe_history("VIX" / "VXN") (Cboe's official history, closed days only) and analysis.vix_view(that series, its last day), write the close, the change from the previous day and the share of the past year's days it is above, citing Cboe with the date. Earnings dates a company has announced go into journal/official_events.csv (ticker,event,date,time,url,checked). Official pages that could not be read go under 「这周没读到的」 (not read this week).
4. Glossary marks (when using the weekly doc): read the 「术语表」 (glossary) tab, save the returned xml to a temporary file and run glossary.save(glossary.marks_from_doc(xml), today in US Eastern time); Lesson's level of explanation depends on it.
5. Rename the session to weekly.tab_name(monday) (mcp__ccd_session_mgmt__set_session_title, when the Claude desktop app provides it).

## During the week (in the week's session; rules in CLAUDE.md, Output conventions)
- The first time I speak each day: check the session's context with mcp__ccd_session_mgmt__get_usage (when available) and remind me to start a new session above 300,000 tokens; then see how far News is up to date and, if it is behind, catch up to the latest trading day from the fixed list (8-K filings at the SEC for watchlist companies, the day's BLS / BEA / Federal Reserve releases, one line for VIX / VXN; no long documents, no blogs, no Form 4 / 144); update the glossary marks as in B.4; then answer.
- When a stock comes up: analysis.prepare(ticker) → analysis.card_markdown(prep), written into this week's Decision; Jev runs automatically with analysis.jev_odds(prep, max_cost_usd=jev.auto_budget()) (within USD 1 a month, no need to ask); only if auto_budget raises CostNotApproved, list 「端点 | 次数 | 单价 | 合计」 (endpoint | calls | unit price | total) with analysis.jev_quote() and wait for my confirmation; log the probabilities with forecast.log_forecasts(analysis.journal_rows(prep)).
- When a company outside the watchlist comes up (watchlist.is_watched is false): after the card, ask me in a pop-up whether to add it, with the suggested area and sub-area as options (start from the areas I set in watchlist.BUCKETS; open a new area if none fits). If I agree, call watchlist.add(...); when using the weekly doc, also add a row at the end of that area's table in the 「关注池」 (watchlist) tab and update the count in its heading (a new area gets a new section).
- When I ask about a US stock during US pre-market, regular, after-hours or overnight trading: the card uses the latest close as usual; add a separate line with the current session's price, change and US Eastern time from quote.extended_hours(["US.<ticker>"]) (if nothing has traded in that session yet, say so).
- When a company announces an earnings date: write it into journal/official_events.csv (with the source link and the date checked); the card will then say 「公司已公布」 (announced by the company).
- My questions (in chat, as @ comments in the doc, or highlighted in the doc): answer briefly where I asked (comments via the docs tool's create utterance, not the Artifact comment tool; clear a highlighted question once it is answered), and record the question in my words, where it was asked and the full answer as a card in this week's Lesson: a knowledge card (one line, analogy, this week's real numbers, common misconceptions, calculations last) or a research card (facts → causes → other explanations → what it means for me, with sources). After the card title, put the 「你的掌握」 (your mastery) dropdown (the same enum as the glossary); explain it differently next time if I mark it 半懂 (partly) or 不懂 (not yet); add new terms to the glossary.
- News and Decision use rounded numbers and carry no explanations; words I have not marked 「懂了」 (got it) in the glossary point to the glossary or to Lesson.

Closing line (investment-related answers): 「教育用途，非投资建议；决定权在你。」 (education only, not investment advice; the decision is yours).
